> สามารถเข้าไปดูแนวข้อสอบได้แล้วที่นี่ [[DSI122 - Module 2 Exam]]

วิชานี้เน้นศึกษาเกี่ยวกับ Data Structures and Algorithms ออกแบบและแก้ไขปัญหาเชิงคำนวณอย่างมีประสิทธิภาพ โดยครอบคลุมตั้งแต่โครงสร้างข้อมูลพื้นฐาน เช่น Linked Lists, Stacks และ Queues การทำความเข้าใจและวิเคราะห์ความซับซ้อนของอัลกอริทึมทั้งเวลาและพื้นที่ (Time & Space Complexity) ด้วยสัญลักษณ์ Asymptotic เช่น Big-O, Big-$\Omega$, Big-$\Theta$ รวมถึงเทคนิคการแก้ปัญหาแบบเวียนเกิด (Recursion) และ Backtracking ตลอดจนกลยุทธ์การออกแบบอัลกอริทึมรูปแบบต่างๆ ไม่ว่าจะเป็น Brute Force, Exhaustive Search, Decrease-and-Conquer และ Divide-and-Conquer ซึ่งประยุกต์ใช้ในการเรียงลำดับ การค้นหาข้อมูล การท่องกราฟ และการแก้ปัญหาเชิงเรขาคณิตหรือการหาค่าเหมาะสมที่สุด (Optimization)
