คืออัลกอริทึมการเรียงลำดับข้อมูลที่ใช้แนวคิดแบบ [[Divide & Conquer]] โดยจะเลือกสมาชิกตัวหนึ่งขึ้นมาเป็น **Pivot** และทำการแบ่งส่วนข้อมูล (Partition) ของอาร์เรย์รอบ Pivot นั้น ด้วยการนำ Pivot ไปจัดวางไว้ในตำแหน่งที่ถูกต้องในอาร์เรย์ที่เรียงลำดับแล้ว

# Time Efficiency
<font color="#ffc000">Average Case</font> & <font color="#00b050">Best Case</font> มีความเร็วระดับ $\Theta(n \log n)$
<font color="#ff0000">Worst Case</font> จะมีความเร็วอยู่ที่ $\Theta(n^2)$

# Pivot
![[Pasted image 20260923214641.png]]
### 1. Choose a Pivot
เลือกสมาชิกหนึ่งตัวจากอาร์เรย์มาเป็น Pivot ซึ่งวิธีการเลือกสามารถทำได้หลากหลายรูปแบบ (เช่น สมาชิกตัวแรก, สมาชิกตัวสุดท้าย, การสุ่มสมาชิก หรือค่ามัธยฐาน)
### 2. Partition the Array
จัดเรียงสมาชิกในอาร์เรย์ใหม่โดยอิงตาม Pivot หลังจากแบ่งส่วนแล้ว สมาชิกทั้งหมดที่มีค่าน้อยกว่าพิวอตจะถูกย้ายไปอยู่ทางด้านซ้าย และสมาชิกทั้งหมดที่มีค่ามากกว่าพิวอตจะไปอยู่ทางด้านขวา
### 3. Recursively Call
นำกระบวนการเดิมไปทำซ้ำแบบเวียนเกิด (Recursion) กับอาร์เรย์ย่อยทั้งสองส่วนที่ถูกแบ่งออก

# Choice of Pivot
### เลือกสมาชิก<font color="#e36c09">ตัวแรก</font>หรือ<font color="#00b0f0">ตัวสุดท้าย</font>เสมอ
การทำงานในตัวอย่างนี้จะเลือกสมาชิกตัวสุดท้ายเป็นพิวอต ข้อเสียของวิธีนี้คือจะส่งผลให้การทำงานตกอยู่ในกรณี <font color="#d83931">Worst case</font> เมื่ออาร์เรย์นั้นถูกเรียงลำดับมาอยู่แล้ว

### สุ่มเลือกสมาชิกขึ้นมาเป็น Pivot
เป็นวิธีที่นิยมมากกว่า เนื่องจากไม่มีรูปแบบข้อมูลชุดใดที่จะทำให้ตกอยู่ในกรณี Worst case ได้อย่างแน่นอน

### เลือกสมาชิกที่มีค่ามัธยฐาน (Median) เป็น Pivot
เป็นวิธีในอุดมคติในแง่ของ [[Time Complexity]] เนื่องจากสามารถหาค่ามัธยฐานได้ในเวลาเชิงเส้น และฟังก์ชันการแบ่งส่วนจะแบ่งอาร์เรย์ออกเป็นสองส่วนเท่าๆ กันเสมอ แต่โดยเฉลี่ยแล้ววิธีนี้ใช้เวลานานกว่า เพราะการหาค่ามัธยฐานมีค่าคงตัว (Constants) ค่อนข้างสูง
