[[Skip List]] คือโครงสร้างข้อมูลที่พัฒนาต่อยอดมาจาก Ordered Linked List (Linked List ที่เรียงลำดับข้อมูลแล้ว) เพื่อทำให้การค้นหาข้อมูลแบบไม่ต้องเรียงตามลำดับทีละตัว (Non-sequential Search) เกิดขึ้นได้ โครงสร้างนี้ใช้หลักการสร้างตัวชี้หลายระดับ (Multiple Levels) ซ้อนกัน โดยจำนวนตัวชี้จะเป็นตัวกำหนดระดับของโหนดนั้น ๆ และจำนวนระดับสูงสุดมีค่าประมาณ $\text{maxLevel} = \lfloor\lg n\rfloor + 1$ การมีตัวชี้หลายชั้นทำให้สามารถ "กระโดดข้าม" ข้อมูลบางส่วนไปได้ ช่วยลดเวลาการค้นหา, เพิ่ม, และลบข้อมูลลงเหลือเฉลี่ย $O(\log n)$ เทียบเท่ากับ Balanced Search Tree แต่จัดการโครงสร้างได้ง่ายกว่า
