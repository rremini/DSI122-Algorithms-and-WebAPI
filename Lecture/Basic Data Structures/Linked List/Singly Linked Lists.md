คือโครงสร้างข้อมูลแบบเชิงเส้น  ที่ประกอบไปด้วยกลุ่มของ **Node** เชื่อมต่อกันแบบทิศทางเดียว โดยโหนดแต่ละตัวไม่ได้ถูกจัดเก็บบนพื้นที่หน่วยความจำที่ติดกันเหมือนอาร์เรย์ แต่จะเชื่อมโยงถึงกันผ่านพอยน์เตอร์หรือตัวชี้อ้างอิง (Pointer / Reference)

### โครงสร้างและการทำงานของ Singly Linked List
Singly Linked List คือโครงสร้างข้อมูลเชิงเส้น (Linear Data Structure) ที่ประกอบด้วย **Node** จำนวนหนึ่ง โดยแต่ละ Node จะเก็บข้อมูล 2 ส่วน:
1. **Data** — ค่าข้อมูลที่ต้องการเก็บ
2. **Next** — Pointer (หรือ reference) ที่ชี้ไปยัง Node ถัดไปในลิสต์

ลิสต์จะมีตัวแปรพิเศษชื่อ **Head** ที่ชี้ไปยัง Node แรกสุด และ Node สุดท้ายจะมีค่า `next` เป็น `null` เพื่อบ่งบอกว่าลิสต์จบแล้ว
![[Pasted image 20260926154307.png]]
```
head -> [10 | next] -> [20 | next] -> [30 | next] -> null
```

### Node Chaining ทำงานอย่างไร?
จุดสำคัญคือ Node แต่ละตัวไม่จำเป็นต้องอยู่ติดกันในหน่วยความจำ (Memory) เหมือน Array — มันสามารถกระจัดกระจายอยู่ที่ไหนก็ได้ สิ่งที่ทำให้ลิสต์ <font color="#92d050">"เป็นเส้นเดียวกัน"</font> คือ Pointer `Next` ที่แต่ละ Node ถืออยู่ ซึ่งทำหน้าที่เหมือน "ลูกโซ่" เชื่อมจากตัวหนึ่งไปอีกตัวหนึ่ง การจะเข้าถึง Node ตัวที่ 5 จึงต้องเดินไล่จาก head ผ่าน Node ที่ 1, 2, 3, 4 ไปเรื่อยๆ ทีละสเต็ป (Sequential Traversal) ไม่สามารถกระโดดไปตำแหน่งใดตำแหน่งหนึ่งได้โดยตรง

### ทำไมต้องมี Linked List ทั้งที่มี Array อยู่แล้ว
ข้อจำกัดของ Array คือมันต้องการพื้นที่หน่วยความจำที่ **ต่อเนื่องกัน** และในภาษาที่เป็น Static array (เช่น C) ต้องกำหนดขนาดตายตัวล่วงหน้า ทำให้เกิดปัญหา:
- **การเพิ่ม/ลบข้อมูลตรงกลางหรือต้นลิสต์มีต้นทุนสูง** เพราะต้องเลื่อน (shift) สมาชิกที่เหลือทั้งหมด
- **การขยายขนาด** ต้องจองพื้นที่ใหม่ที่ใหญ่ขึ้นแล้วคัดลอกข้อมูลทั้งหมดไปที่ใหม่ (resize) ซึ่งมีต้นทุนสูงในกรณีเลวร้ายที่สุด

Linked List แก้ปัญหานี้โดย **จัดสรรหน่วยความจำแบบไดนามิก ทีละ Node** เมื่อจะเพิ่มหรือลบข้อมูล เราเพียงแค่เปลี่ยนค่า pointer ให้ชี้ไปยัง Node ที่ถูกต้อง โดยไม่ต้องขยับข้อมูลตัวอื่นเลย นี่คือเหตุผลที่ Linked List เหมาะกับสถานการณ์ที่ขนาดข้อมูลไม่แน่นอนหรือมีการแทรก/ลบบ่อยที่ต้นลิสต์

### ตัวอย่างการเขียนโค้ด (JavaScript ES6)

```javascript
// constructor to initialize a new node with data
class Node {
    constructor(new_data) {
        this.data = new_data;
        this.next = null;
    }
}

// Create the first node (head of the list)
let head = new Node(10);

// Link the second node
head.next = new Node(20);

// Link the third node
head.next.next = new Node(30);

// Link the fourth node
head.next.next.next = new Node(40);

// printing linked list
let temp = head;
while (temp !== null) {
    process.stdout.write(temp.data + " ");
    temp = temp.next;
}
```
