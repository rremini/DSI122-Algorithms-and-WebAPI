Linked List คือโครงสร้างข้อมูลที่ประกอบขึ้นจากกลุ่มของ Nodes โดยแต่ละโหนดจะทำหน้าที่จัดเก็บข้อมูล และการอ้างอิงหรือตัวเชื่อมโยง ไปยังโหนดอื่นในรายการ ซึ่งมีทั้งรูปแบบ Singly Linked List ที่มีการเชื่อมต่อไปยังโหนดถัดไปเพียงทิศทางเดียว Doubly Linked List ที่มีตัวเชื่อมโยงไปยังทั้งโหนดก่อนหน้าและโหนดถัดไป รวมถึง Circular List ที่เชื่อมต่อวนกลับมาเป็นวง โดยข้อดีของ Linked List คือสามารถแทรกหรือลบข้อมูลได้ง่ายเนื่องจากส่งผลกระทบเฉพาะจุด แต่มีข้อจำกัดตรงที่ไม่สามารถเข้าถึงข้อมูลแบบสุ่มได้เหมือนกับ Array

## สรุปภาพรวม

| โครงสร้าง                   | แก้ปัญหาของอะไร                    | จุดเด่น                                    |
| --------------------------- | ---------------------------------- | ------------------------------------------ |
| **Doubly Linked List**      | Singly Linked List ถอยหลังไม่ได้   | เดินสองทิศทาง ลบเร็ว                       |
| **Skip List**               | Linked List ค้นหาช้า               | "ทางด่วนหลายชั้น" ค้นหา O(log n) โดยเฉลี่ย |
| **Sparse Table (เมทริกซ์)** | อาร์เรย์ 2 มิติเปลืองที่กับค่า 0   | เก็บเฉพาะช่องที่มีค่า                      |
| **Sparse Table (RMQ)**      | การหา min ช่วงช้าถ้าทำซ้ำหลายครั้ง | คำนวณล่วงหน้า ตอบ O(1)                     |
