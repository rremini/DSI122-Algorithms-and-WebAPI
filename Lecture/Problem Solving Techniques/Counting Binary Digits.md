**Counting Binary Digits** (หรือ Counting bits) คือ การหาหรือนับจำนวนหลักของเลขฐานสอง ฃที่ใช้แทนค่าจำนวนเต็มบวกในระบบเลขฐานสิบ ($n$)

### 1. หลักการทำงานของ Counting Binary Digits
เมื่อเรามีจำนวนเต็มบวก $n$ ในระบบฐานสิบ การแปลงเป็นเลขฐานสองจะต้องใช้จำนวนหลัก (Bits) ทั้งหมด $\lfloor \log_2 n \rfloor + 1$ หลัก ตัวอย่างเช่น:
- เลข $1$ แปลงเป็นฐานสองได้คือ $1_2$ (ใช้ 1 บิต)
- เลข $4$ แปลงเป็นฐานสองได้คือ $100_2$ (ใช้ 3 บิต)
- เลข $13$ แปลงเป็นฐานสองได้คือ $1101_2$ (ใช้ 4 บิต)

ในขั้นตอนวิธี (Algorithm) สามารถคำนวณจำนวนหลักของเลขฐานสองได้ 2 รูปแบบหลัก:
### 2. รูปแบบขั้นตอนวิธีและการสอนการคำนวณ

#### 2.1 Non-recursive Algorithm หรือ Iterative Algorithm
อัลกอริทึมชื่อ **`Binary(n)`** ทำงานโดยใช้ลูปวนซ้ำ (While loop):

```
ALGORITHM Binary(n)
//Input: A positive decimal integer n
//Output: The number of binary digits in n's binary representation
count ← 1
while n > 1 do
    count ← count + 1
    n ← ⌊n/2⌋
return count
```

- **Input:** จำนวนเต็มบวก $n$
- **Output:** จำนวนหลักของเลขฐานสองที่ใช้แทนค่า $n$
- **หลักการทำงาน:**
    - กำหนดค่าเริ่มต้นของตัวนับ `count ← 1`
    - ทำการตรวจสอบเงื่อนไขในลูปว่า `while n > 1` หรือไม่
    - ในแต่ละรอบจะเพิ่มค่าตัวนับขึ้น 1 (`count ← count + 1`)
    - ลดขนาดของค่า $n$ ลงด้วยการหารสองแล้วปัดเศษลง (`n ← ⌊n/2⌋`)
    - เมื่อค่า $n$ ลดลงจนไม่มากกว่า 1 จะหลุดออกจากลูปและคืนค่า `count` ออกมา

## ตัวอย่างการทำงานเมื่อ $n = 5$:
1. เริ่มต้น: `count = 1`, `n = 5`
2. รอบที่ 1: ตรวจสอบ $5 > 1$ (จริง) $\rightarrow$ `count = 2`, $n = \lfloor 5/2 \rfloor = 2$
3. รอบที่ 2: ตรวจสอบ $2 > 1$ (จริง) $\rightarrow$ `count = 3`, $n = \lfloor 2/2 \rfloor = 1$
4. รอบที่ 3: ตรวจสอบ $1 > 1$ (เท็จ) $\rightarrow$ สิ้นสุดการวนซ้ำ
5. คืนค่าผลลัพธ์ `count = 3` (เพราะ $5_{10} = 101_2$ มี 3 บิต)

#### 2.2 รูปแบบ Recursive Algorithm
อัลกอริทึมชื่อ **`BinRec(n)`** ใช้วิธีเรียกตัวเองซ้ำเพื่อแก้ปัญหาย่อย:

```
ALGORITHM BinRec(n)
//Input: A positive decimal integer n
//Output: The number of binary digits in n's binary representation
if n = 1 return 1
else return BinRec(⌊n/2⌋) + 1
```

- **Input:** จำนวนเต็มบวก $n$
- **Output:** จำนวนหลักของเลขฐานสองที่ใช้แทนค่า $n$
- **หลักการทำงาน:**
    - **Base Case (กรณีฐาน):** ถ้า $n = 1$ จะคืนค่าทันทีเป็น $1$
    - **Recursive Step (ขั้นตอนเวียนเกิด):** ถ้า $n > 1$ จะเรียกตัวเองซ้ำด้วยขนาดอินพุตที่หารสอง $\lfloor n/2 \rfloor$ แล้วนำผลลัพธ์ที่ได้มาบวกเพิ่มอีก $1$ (`BinRec(⌊n/2⌋) + 1`)

### 3. Time Efficiency Analysis

จากอัลกอริทึมแบบเวียนเกิด `BinRec(n)`:
- **Basic Operation (ปฏิบัติการพื้นฐาน):** คือการบวก (Addition)
- **Recurrence Relation (ความสัมพันธ์เวียนเกิด):**
    - $A(n) = A(\lfloor n/2 \rfloor) + 1$ โดยมีเงื่อนไขเริ่มต้น $A(1) = 0$
- **การหาผลเฉลยสำหรับ $n = 2^k$:**
    - กำหนดสมการเมื่อ $n$ เป็นเลขยกกำลังสอง: $A(2^k) = A(2^{k-1}) + 1$ สำหรับ $k > 0$ โดยที่ $A(2^0) = 0$
    - ใช้ **Backward Substitution** (การแทนค่าย้อนกลับ):
        - $A(2^k) = A(2^{k-1}) + 1 = A(2^{k-2}) + 2 = \dots = A(1) + k = k$
        - ถ้า $n = 2^k$ จะได้ว่า $k = \log_2 n$          
        - ดังนั้น $A(n) = \log_2 n$
- สรุปอัตราการเติบโตเชิงเวลา (Order of Growth) อยู่ในกลุ่ม **Logarithmic Efficiency ($\Theta(\log n)$)** ซึ่งทำงานได้รวดเร็วมากเมื่อเทียบกับขนาดของตัวเลข $n$

### 4. Technical Terms

| คำศัพท์                                           | ความหมาย<br>                                                                                                                                                       |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Binary Digits (Bits)**                          | ตัวเลขโดดในระบบเลขฐานสอง มีค่าได้เพียง 0 หรือ 1<br>                                                                                                                |
| **Input Size**                                    | ขนาดของข้อมูลนำเข้า ซึ่งใช้เป็นพารามิเตอร์วัดประสิทธิภาพและการทำงานของขั้นตอนวิธี                                                                                  |
| **Basic Operation:**                              | ปฏิบัติการพื้นฐานที่ส่งผลต่อเวลาการประมวลผลของอัลกอริทึมมากที่สุด                                                                                                  |
| **Recursive Algorithm**                           | ขั้นตอนวิธีแบบเวียนเกิด คือขั้นตอนวิธีที่ฟังก์ชันมีการเรียกใช้งานตัวเองเพื่อแก้ปัญหาย่อยที่มีขนาดเล็กลง                                                            |
| **Non-recursive Algorithm / Iterative Algorithm** | ขั้นตอนวิธีแบบไม่เวียนเกิด หรือแบบวนซ้ำ ซึ่งใช้โครงสร้างการควบคุมแบบวนรอบ (Loop) ในการคำนว                                                                         |
| **Recurrence Relation**                           | ความสัมพันธ์เวียนเกิด คือสมการทางคณิตศาสตร์ที่นิยามค่าของฟังก์ชันในรูปของฟังก์ชันตัวมันเองด้วยอินพุตขนาดเล็กลง ใช้สร้างแบบจำลองวิเคราะห์เวลาของอัลกอริทึมเวียนเกิด |
| **Backward Substitution**                         | วิธีการแทนค่าย้อนกลับ เป็นเทคนิคทางคณิตศาสตร์ในการแก้สมการเวียนเกิดโดยกระจายพจน์ถอยหลังไปจนถึงเงื่อนไขเริ่มต้น                                                     |
| **Floor Function ($\lfloor x \rfloor$)**          | ฟังก์ชันปัดเศษลง เป็นการตัดเศษทศนิยมออกให้เหลือเพียงจำนวนเต็มที่น้อยกว่าหรือเท่ากับค่านั้น                                                                         |
| **Time Efficiency / Order of Growth**             | ประสิทธิภาพเชิงเวลาและอัตราการเติบโตของการใช้เวลาประมวลผลเมื่อขนาดของข้อมูลนำเข้า ($n$) มีขนาดใหญ่ขึ้น                                                             |
