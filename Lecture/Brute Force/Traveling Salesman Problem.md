### โจทย์
มี n เมือง และรู้ระยะทางระหว่างทุกคู่ ต้องหา **tour** ที่สั้นที่สุด โดยเดินผ่านทุกเมือง **เมืองละครั้งเดียว** แล้วกลับมาที่เมืองเริ่มต้น

เขียนในภาษากราฟได้ว่า คือการหา **Shortest Hamiltonian Circuit** ใน **weighted connected graph**
### Hamiltonian circuit
วงจรที่เป็นลำดับของ n+1 จุดยอด (vertices) ติดกัน โดยจุดแรกกับจุดสุดท้ายเป็นจุดเดียวกัน ส่วนอีก n−1 จุดที่เหลือต้องไม่ซ้ำกัน
### Weighted graph
กราฟที่แต่ละเส้นเชื่อม (edge) มีน้ำหนัก เช่น ระยะทางหรือค่าใช้จ่าย

---

## วิธีทำด้วย Exhaustive Search
เนื่องจาก tour คือการเรียงลำดับเมือง และเมืองเริ่มต้นถูกกำหนดไว้แล้ว เราจึงสร้าง tour ทั้งหมดจาก **permutations** ของเมืองระหว่างทาง n−1 เมือง แล้วคำนวณ cost ของแต่ละ tour เลือกอันที่น้อยที่สุด

### ตัวอย่างจากสไลด์ (4 เมือง)
![[Pasted image 20260924080105.png]]
ระยะทาง: a–b = 2, a–c = 8, a–d = 5, b–c = 3, b–d = 4, c–d = 7

| Tour      | Cost             |
| --------- | ---------------- |
| a→b→c→d→a | 2+3+7+5 = **17** |
| a→b→d→c→a | 2+4+7+8 = 21     |
| a→c→b→d→a | 8+3+4+5 = 20     |
| a→c→d→b→a | 8+7+4+2 = 21     |
| a→d→b→c→a | 5+4+3+8 = 20     |
| a→d→c→b→a | 5+7+3+2 = **17** |
คำตอบที่ดีที่สุดคือ cost = 17 (ได้สองเส้นทาง)
